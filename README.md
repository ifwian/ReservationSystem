# FRAME Gaming Café — Milestones

A reservation website for a fictional gaming café, built in 8 cumulative steps. No database: mock data first, then browser localStorage. `milestone_8` is the final working version.

| Folder | Adds |
|---|---|
| `milestone_1` | Static HTML page + basic CSS |
| `milestone_2` | Flexbox/Grid layout, responsive breakpoints, wrapped mobile nav (no JavaScript yet) |
| `milestone_3` | `app.js`: stations and pricing from a mock array, mobile menu button |
| `milestone_4` | Reservation form with validation (saves nothing yet) |
| `milestone_5` | localStorage `Store`, **Create**, confirmation |
| `milestone_6` | Admin page: **Read**, status counts |
| `milestone_7` | **Update** and **Delete** (CRUD complete) |
| `milestone_8` | No double booking, search/filter, past-date check, `TESTING.md` |

Each folder contains the full code at that step. Read its `README.md` first. The admin page is public on purpose in this version; a real login needs a backend, which is the consultation topic.
